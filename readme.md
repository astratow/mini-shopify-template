# Shopify Theme From Scratch (OS 2.0)

A lightweight, opinionated Shopify Online Store 2.0 theme.

The goal of this project is simplicity, performance, and clarity — no bloated features, no unnecessary abstractions.

---

## 🎯 Project Goals

- Built **from scratch** (no Dawn fork)
- Optimized for **single-product stores**
- OS 2.0 architecture (JSON templates + sections)
- Minimal CSS & JS
- Easy to extend and customize
- Developer-friendly structure

---

## 🧱 Tech Stack

- Shopify Online Store 2.0
- Liquid
- JSON templates
- Vanilla CSS
- Vanilla JavaScript
- Shopify CLI

## 🚀 Getting Started

### 1️⃣ Prerequisites
